This feed is managed entirely through GitHub Issues.

- Open a **New post** issue to publish.
- Open an **Edit post** issue to modify an existing entry.
- Open a **Delete post** issue to remove one.
- Open a **New category** issue to register a new category.

GitHub Actions apply the change, rebuild the site and deploy to Cloudflare Pages automatically.

Subscribe via RSS: [feed.xml](https://pulsar-feed.pages.dev/feed.xml).
